# 双人合盘网站（简约版原型）

一个前端原型：输入 A/B 出生信息后，批量生成以下星盘模块并给出解读：

- A 本命盘
- B 本命盘
- 双方比较盘
- 时空三限 / 时空次限 / 时空盘
- 组合三限 / 组合次限 / 组合盘
- 马盘三限 / 马盘次限 / 马盘
- A 月亮返照盘 / B 月亮返照盘

## 使用方式

直接打开 `index.html` 即可。

## 说明

- 动态盘支持按“年月日”调整，修改后会更新盘面与解读。
- 提供“前一天 / 后一天”快捷切换动态日期。
- 每张盘展示所有行星与虚拟点。
- 新增 A↔B 关键相位表（太阳、月亮、水星、金星、火星）与整体评分条（沟通/吸引/稳定/成长）。
- 支持导出 JSON 结果，便于后续接入后端存档或报告生成。
- 当前版本为 UI/交互原型，盘面算法采用可复现的占位计算，便于后续替换为真实占星引擎（如 Swiss Ephemeris + 时区/地理坐标）。
